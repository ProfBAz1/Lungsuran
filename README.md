# Lungsuran
Lungsuran lahir dari kebiasaan baik masyarakat Indonesia mewariskan barang layak pakai kepada kerabat atau tetangga terdekat. Kami membangun ruang transaksi Consumer-to-Consumer (C2C) hiper-lokal agar barang preloved berkualitas tidak menumpuk menjadi limbah, sekaligus memberi panggung bagi perajin handmade skala rumahan.
